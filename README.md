# 地图统一作业版 · 移动端原型

新版入口为 `index.html`。本目录保留的14个旧HTML用于方案对照，不是新版流程入口；原 `移动端/` 与 `pc-任务管理/` 未改动。

## 打开方式

在项目根目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8766/移动端-地图统一作业版/index.html`，不要使用 file:// 验证地图与定位。

## 评审操作

1. 任务管理默认展示有未结束任务的商户，一个商户一个维护地址。按风控筛选后打开青禾便利，详情仍展示该商户所有任务。
2. 领取商户，填写任务表单并提交。保存草稿、导航、普通走访不解除72小时首次处理期限。到期前24小时可在特殊作业筛选查看。
3. 需审核任务提交后进入审核中；查看记录里的演示工具可模拟原有审核通过/驳回，不新增审批。
4. 商户作业中的折叠演示工具可模拟新任务下发，验证领取继承；回收或全部结束后新增任务重新待领取。
5. 走访可关联本商户任务；没有合格定位必须填写未核验原因，不计有效到店。结果为“其他”时必须填写备注。可按日期筛选走访。
6. 地址校正保存后立即更新导航目的地并留历史；目标商户可标意向、演示进件失败或成功、绑定正式号、填写原因后放弃，不增加审批。
7. 切换商户热力图入口，演示点位、热力、网点和半径开关。任务与数据入口各自保留筛选。详情已完成任务可看近90天或全部历史，不删除记录。

## 高德与数据边界

- 设置中填写本人有权使用的高德 Web JS API Key、安全配置或测试安全代理；仅存当前浏览器 sessionStorage，不写入代码。不要填写生产密钥。
- 无Key时明确显示“交互示意 · 非真实地图”；示意热力不代表已接通Loca，示意选点不等于人员定位。
- 已实现高德 JS API 2.0 与 Loca 2.0 适配；真实底图、真实热力及鉴权/配额异常尚待合法Key验证。移动真机人员定位需HTTPS和授权，微信内导航唤起也需真机验证。
- 商户、位置、银行材料均为虚构演示数据；业务写入只在 localStorage。关闭或刷新仍保留状态，不连接正式后台。PDF只保存文件元信息，图片保存压缩缩略图，不提供真正材料上传。
- 真实并发锁、权限隔离、服务端事务、回执幂等、性能与通知不由本原型替代。回收在读取数据时执行，不是后台定时服务；即将回收提示不是系统推送。
- 原型只有一个演示网点；多网点归属、跨机构权限和大数据量不属于已验证能力。未知完成时间的旧演示任务仍可见，不臆造完成日期。
