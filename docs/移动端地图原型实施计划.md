# 移动端地图原型实施计划

**依据**：商户热力图与地图任务管理PRD.md V1.1，用户已确认并授权实现。

**目标**：只在复制目录交付可操作、可验证的移动端地图作业原型；不修改原移动端和 PC，不创建生产后端。

**技术**：纯 HTML/CSS/JavaScript，复用已有手机壳；业务状态通过本原型专用 localStorage 持久化；高德 JS API 2.0 + Loca 2.0。缺少合法 Key 时明确显示交互示意，不冒充真实 SDK。

## 文件职责

- `移动端-地图统一作业版/index.html`：新原型入口，统一地图、数据入口、详情与作业表单。
- `prototype.css`：移动端布局、底部抽屉、详情和表单样式。
- `prototype-app.js`：页面路由、筛选、任务/商户操作以及反馈。
- `prototype-store.js`：演示数据、领取/任务/走访/意向/校正状态，Node可测试。
- `map-adapter.js/css`：高德真实地图与明确标识的缺配置交互示意，点位、热力、网点圈、选点。
- `tests/map-prototype-store.test.js`：状态与边界验证。
- 浏览器交互测试及截图放临时目录，最终必要操作说明放复制目录 README。
