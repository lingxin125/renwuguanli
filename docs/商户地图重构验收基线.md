# 商户地图重构验收基线

以2026年10月8日用户重新确认的场景为准。旧文档中的“地图替代任务列表、强制默认未结束任务、两个独立地图工作台”不再作为本轮实施基线。

## 页面与业务边界

- 新增独立“商户地图”入口，进入即地图，原任务列表及原详情页保留。
- 默认显示全部授权正式、目标、意向商户，包括无任务商户；商户点位开启，热力关闭。
- 初始视野为全国，按商户地理位置分布；全国地图数据独立于原任务列表数据。
- 默认只展示地图点位，不展示底部结果面板；点击聚合点展开该组商户，点击单户点位或组内商户后才展示商户卡片。
- 低缩放层级使用小型商户图标与聚合数字，不展示拥挤的名称、任务角标；高缩放后再展示名称。
- 一户对应一个当前维护的走访地址。按商户ID去重，不因多个任务或相同地址合并不同商户。
- 点位颜色表达商户阶段；活跃状态、近期交易、特殊场景独立筛选/标签。无坐标商户进入未定位列表，不能生成假点位。
- 搜索商户号唯一匹配后聚焦对应商户、打开卡片；名称支持多结果；清除搜索恢复原筛选。
- 顶部“更新定位”更新人员当前位置，不能修改商户坐标；商户位置通过独立校正操作更新。
- 热力按筛选后的有坐标商户密度，每户权重1。点位开关不改变商户集合、计数和热力；热力失败需明确提示。
- 商户卡片只展示核心信息，提供导航到店、查看商户；存在任务时才展示查看任务。
- 正式商户“查看商户”按用户要求保留按钮和接入提示，不另造正式商户详情。
- 目标/意向“查看商户”分别跳原目标/意向详情；查看任务跳原商户任务详情。保留返回地图上下文。
- 复用PPT的点位开关、定位、网点位置/辐射圈、意向标记、地址校正等能力，不引入行业内容。
- 地图优先使用高德原生缩放、比例尺、地图类型控件，保留卫星图、路网和路况。
- 正文不显示模拟、演示、测试等实现说明；不在产品界面提供Key输入框。

## 验收证据

真实高德底图、点位、聚合、Loca热力、地图缩放、定位/拒绝授权、准确商户号搜索、无结果、无坐标、组合筛选、点位关闭、热力关闭、网点圈层、导航链接、三类商户卡片、条件任务按钮、原页面跳转、返回恢复、地址校正取消/保存/失败、意向标记均需明确验证。

视觉检查覆盖320/390/430像素移动视口及桌面手机框；核对文字对比度、14px正文、标准图标、44px可点击控件、卡片与地图遮挡、底部安全区、横向溢出。

完成时区分真实地图验证、业务本地状态验证、原型跳转验证与尚未接入的正式业务系统能力。禁止用替代SDK或假地图通过的测试宣称真实高德验收。

## 自动化执行与已验证范围（2026-10-08）

运行本地静态服务后，使用实际服务地址运行：

```powershell
$env:TASK_MGMT_TEST_ORIGIN='http://127.0.0.1:8766'
node --test tests/browser-smoke.test.js tests/map-prototype-store.test.js tests/mobile-shell.test.js
```

浏览器套件使用本机 Chrome 和页面实际配置的高德 SDK，不替换底图；等待底图、聚合点及异步原生控件就绪。

本轮执行已验证：手机壳、原任务列表、全景报告、全国地图默认无列表、热力模块及开关、组内聚合列表、单户卡片、导航 URL、原任务详情跳转、正式商户搜索及详情提示、目标商户原详情跳转。浏览器交互脚本 `tests/merchant-map.browser.js` 另外覆盖无结果清理、图层弹窗、阶段筛选、320/390/430/1200宽度无横向溢出和运行错误检查。

视觉层按 Product Design 审计保留邮付绿色系，采用统一 Tabler 图标，统一搜索、分段筛选、悬浮控件及商户卡片层级；不修改原详情页面内容。

补充验收：聚合标记收紧到28px，单商户标记24px，增加透明点击命中区域；隐藏非必要地图统计浮层。320×640短屏已复现并修复卡片越出可视区域，卡片可滚动到达操作按钮。高德原生卫星选项通过正常点击切换，并在本轮截图中确认实际卫星底图已呈现。全国热力开启后的截图确认实际密度图层呈现。专项脚本增加标记尺寸、浮层隐藏、短屏卡片及底图菜单收起回归检查。

新增边界脚本 `tests/merchant-map-boundaries.browser.js`，通过 Playwright 的 `browser_run_code_unsafe` 以 filename 运行。使用独立浏览器会话和真实高德 SDK，不改用户当前商户记录。验证27项：高德菜单键盘开合、点位与热力独立开关、1000米网点圆、阶段/活跃/交易/任务组合筛选、精确搜索覆盖冲突筛选、未定位不造点、定位坐标转换成功且商户坐标不变、定位拒绝/不可用/超时提示、意向电话校验及刷新持久化、校正取消/越界/空白原因/存储失败/刷新持久化、导航坐标参数、单户标记点击、目标/意向/任务原详情返回地图搜索卡片。故障分支只在独立测试会话注入设备或存储异常；不宣称已进行真机定位授权或App唤起验收。

本轮修复高德菜单键盘处理、全国商户校正空白校验与中文保存失败提示；仅对地图来源的详情返回补上下文，原详情内容不变，任务列表来源返回不变。

新增恢复脚本 `tests/merchant-map-recovery.browser.js`，通过 Playwright 的 `browser_run_code_unsafe` 以 filename 运行。9项通过：原生路网与路况勾选实际挂载高德RoadNet/Traffic图层、设备定位回调乱序、坐标转换回调乱序和旧错误不覆盖新提示、阻断Loca后底图点位仍可用、解除阻断后热力恢复且清除旧提示、阻断SDK后不生成伪地图点位/热力、明确重连入口和网络恢复后原地重连。仅在独立测试会话控制网络/定位时序，原页面不暴露测试入口或凭据输入。

本轮修复定位请求序号保护、热力恢复状态、未连接时停止绘制本地地图对象，并新增故障时的“重新连接”操作。路网/路况已经验证SDK图层挂载，尚不能据此宣称各城市实时交通瓦片完整加载或覆盖完整。

仍需补齐的验收：鉴权/地图完成超时故障、低缩放聚合到高缩放拆分的多地区验证、标签/特殊场景筛选、细分可访问性/字体可靠性，以及真机导航 App 唤起。当前自动化通过不代表这些尚未覆盖项已经验收。全国商户数据为本地原型业务数据，不是已接入的生产商户接口；城市商圈坐标未逐户地理编码核验。
