1. 任务分类

1.1 存量商户任务

主要针对平台内已签约的正式商户，进行持续的维护与服务提升。

  • 切换通道任务
  • 合并补充商户资料任务
  • 走访维护商户任务
  • 风控任务
  • 挂帐任务

1.2 目标商户任务

核心目标: 拓客，将潜在商户转化为平台的正式商户。

转化路径: 目标商户 ➔ 意向商户 ➔ 平台正式商户

核心功能模块:

  • 目标商户走访 (通过此模块实现商户的逐级转化)

2. 功能模块

PC 端

正式商户任务管理

  • 下发任务
  • 查看任务进度
  • 查看任务详情
  • 筛选

目标商户任务管理

  • 下发任务
    • 批量导入
  • 查看目标商户的任务进度
  • 查看任务详情
  • 筛选
  • 地图形式展示 (围栏下发和点选指派的任务)

任务驾驶舱 (任务管理统计)

  • 正式和目标商户的数量统计 (按类型区分)
  • 任务完成度统计
  • 地图区域分布等统计功能

移动端

正式商户任务

  • 客户经理查看所属网点下的商户
  • 领取任务 (领取后所有任务归属该客户经理)
  • 走访完成
  • 支持地图查看商户
  • 可导航到商户

目标商户任务

商户层级递进: 目标商户 ➔ 意向商户 ➔ 正式商户

区分以上三个不同层级的商户类型，逐级加深，最终转化为正式商户。

  • 展示所有已下发以及客户经理自己拓展的目标商户
  • 通过进一步走访进行转化

3. 任务下发及流转说明

所有任务都是最终下发到 网点，进而是 客户经理。

客户经理通过 领取 或 被指派 的方式获取任务，然后完成任务。

机构层级:

省 ➔ 市 ➔ 区县 ➔ 网点

各个商户均归属于其对应的 网点。

任务下发后，客户经理可在移动端根据自身当前距离，展示附近的商户，便于高效规划和执行走访任务。
