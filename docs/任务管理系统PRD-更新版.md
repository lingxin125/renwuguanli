# 任务管理系统（手机端）PRD文档（更新版）

## 1. 产品背景与目标

随着线下商户拓展、维护及任务管理需求的提升，需建设一套高效、易用的手机端任务管理系统，支持业务人员对商户任务的全流程管理，包括商户领取、处理、跟进、转化等，提升工作效率与数据透明度。

## 2. 主要用户与场景

- **主要用户**：
  - 业务员/客户经理：负责商户拓展、走访、资料补充、任务处理等。
  - 主管/管理人员：关注任务分布、进度、业绩等。
- **典型场景**：
  - 外出拜访商户，随时领取商户、处理相关任务。
  - 地图模式下快速定位附近商户及任务。
  - 新增目标商户，采集基础信息与现场照片。
  - 跟进商户转化、业绩录入、资料完善等。
  - 商户超时、任务驳回、补充资料等多种业务场景。

## 3. 主要功能模块

### 3.0 任务类型选择页（新增）
- 登录后首先进入任务类型选择页，客户经理需先选择"存量商户"或"目标商户"类型。
- 选择"存量商户"后，进入任务列表页（商户）。
- 选择"目标商户"后，进入任务列表页（目标商户）。
- 任务类型选择页风格与整体一致，卡片式入口，支持后续扩展。

### 3.1 任务列表页（商户）
- 展示所有存量商户及其相关任务，分为"待领取"和"已领取"两大tab页签，支持数量统计。
- 支持商户任务的搜索（商户名称/商户号）、筛选（如任务类型、距离、状态等）、排序（如距离、任务数、更新时间等）。
- 支持列表模式与地图模式切换，切换时保留筛选与排序条件。
- 商户卡片展示：
  - 商户名称、商户号、距离、待办任务数、任务类型标签。
  - 卡片高亮显示超时、被驳回等特殊状态。
  - "待领取"tab下，卡片右侧垂直居中显示"领取商户"按钮，点击弹窗确认领取，领取后商户及其任务归属当前客户经理，3天有效期。
  - "已领取"tab下，卡片右侧垂直居中显示进入详情页的icon按钮。
  - "已领取"tab下，若商户下有任务即将失效（如3天内未处理任何任务），卡片右上角显示"即将失效"橙色标签，并高亮卡片（浅橙色背景+橙色边框），且这些卡片自动置顶，优先展示。
  - 卡片布局采用主内容左侧、操作按钮/图标右侧的分区方式，提升可读性和操作效率。
  - 领取弹窗文案优化：领取后3天内需处理至少1个任务，逾期需重新领取商户。
  - 任务类型标签多色区分（如补充资料、切换备用通道、走访维护商户、风控处理、挂账处理等）。
  - "已领取"tab下增加分段器，分为"进行中"和"已完成"两段，并分别统计数量。
  - "进行中"分段展示当前客户经理已领取但未全部完成任务的商户，支持进入详情页继续处理。
  - "已完成"分段展示当前客户经理90天内已全部完成任务的商户，默认按完成时间降序排序，不支持单独排序和筛选，卡片仅展示基础信息和完成时间，不再支持领取、处理等操作。
  - 商户下所有任务完成后，自动从"进行中"归类到"已完成"分段。
  - "已完成"分段支持分页或滚动加载，避免页面卡顿。
  - 分段器切换时，数据和数量统计实时刷新。
- 支持分页与下拉刷新。
- 支持筛选弹窗，任务类型多选互斥，筛选条件可重置。
- 排序下拉菜单，支持多种排序方式切换。
- tab页签切换，支持实时统计数量。
- 异常与边界场景：
  - 搜索无结果时，展示友好提示及重置筛选按钮。
  - 网络异常时，展示重试按钮。
  - 商户任务数为0时，卡片灰显。
  - 权限不足时，隐藏或禁用相关操作。
- 交互细节：
  - 搜索框聚焦高亮，失焦恢复。
  - 筛选、排序、tab切换、领取弹窗等均有过渡动画和友好交互。
  - 领取任务弹窗需二次确认，领取后状态实时更新。
  - 领取后超时需重新领取，系统自动提醒。
### 地图模式
- 地图模式作为任务列表页（商户）的补充视图，支持与列表模式一键切换，切换时保留筛选、排序等条件。
- 地图上以点位形式展示所有商户，点位颜色/样式根据商户状态区分（如进行中、即将超时等），不再区分“正式商户/意向商户”标签。
 - 仅保留“待领取”“已领取”两个tab页签：
 - “待领取”tab：仅展示未领取的商户。
 - “已领取”tab：仅展示进行中的商户（已领取但未全部完成任务），不再支持分段器切换“进行中/已完成”，如需查看已完成商户请切换到列表模式。
 - 切换到“已领取”tab时，页面顶部有提示：“地图模式仅显示进行中的商户，若要查看已完成商户，请切换到列表模式”。
 - 点击地图点位或底部列表项，弹出商户卡片，展示商户基础信息、距离、任务数、任务类型标签等，卡片右侧仅保留“导航到此处”或“领取商户”按钮。
 - 若商户即将超时，卡片高亮并显示“即将失效”标签。
 - 地图下方为可展开/收起的底部商户列表，内容与地图点位同步，支持点击高亮联动。
 - 支持任务类型筛选（去除商户类型筛选）、距离/任务数排序，所有筛选、排序条件与列表模式保持一致，切换视图时条件保留。
 - 支持地图缩放、定位、重置等基础操作，地图加载失败时允许重试。
 - 搜索、筛选、排序、领取等交互与列表模式一致，无数据、网络异常等场景有友好提示。

### 3.2 任务列表页（目标商户）
- 展示所有目标商户及其相关任务。
- 支持目标商户的筛选、搜索、排序、领取、转化等操作。
- 其他功能与存量商户任务列表页保持一致，风格统一。

### 3.3 新增目标商户
- 表单采集商户基础信息（名称、联系人、电话、地址、行业等），所有必填项有明显标识。
- 支持地图定位、手动输入地址，定位失败时允许手动输入。
- 必填项校验，支持备注，输入格式校验（如手机号、地址长度等）。
- 支持上传门头照等打卡照片，照片支持预览、删除、重新上传。
- 支持返回原列表页，返回前有未保存内容时弹窗确认。
- **异常与边界场景**：
  - 表单未填写完整时，禁止提交并高亮提示。
  - 图片上传失败时，允许重试。
  - 网络异常时，保存为草稿，待网络恢复后自动提交。
  - 重复商户名/电话时，弹窗提示并阻止提交。

### 3.4 商户任务详情页
- 展示当前商户下的所有任务，支持分段查看不同状态（待处理、审核中、已驳回、已完成）。
- 领取概念已上升到商户纬度，商户详情页不再区分"待领取/已领取"tab页签。
- 顶部仅保留分段控制器（分段器），支持切换查看各状态任务。
- 每个任务卡片展示任务名称、类型、创建/处理/完成时间、处理人、标签、状态、操作按钮（如去处理、查看详情、重新提交等）。
- 支持任务的领取、处理、重新提交、查看详情等操作（如有权限）。
- 支持任务状态高亮、驳回原因提示、剩余时效等信息展示。
- 通知提醒：如有任务超时、被驳回等，顶部展示高亮通知卡片，支持关闭。
- 交互细节：
  - 分段器切换有动画，任务卡片支持悬浮高亮。
  - 操作按钮有过渡反馈。
- 异常与边界场景：
  - 无任务时展示"暂无任务"提示。
  - 网络异常、权限不足等场景有友好提示。

### 3.5 意向商户详情页
- 展示意向商户基础信息、机构信息、照片、业绩、操作人信息等。
- 支持编辑、放弃商户、业绩录入等。
- 支持跳转至相关任务、业绩编辑。
- 商户状态支持"已转化"、"已放弃"等，状态变化有明显提示。
- 照片支持多张上传、预览、删除。
- **异常与边界场景**：
  - 放弃商户需二次确认，防止误操作。
  - 编辑信息时，未保存直接离开弹窗确认。
  - 业绩录入失败时，允许重试。
  - 无照片时，展示占位图。

### 3.6 目标商户详情页
- 展示目标商户基础信息、打卡状态、照片、业绩、备注等。
- 支持仅打卡、意向商户转化等操作。
- 支持业绩新增、备注填写。
- 打卡状态实时更新，支持补打卡。
- **异常与边界场景**：
  - 打卡失败时，允许重试。
  - 转化操作需二次确认。
  - 备注内容过长时自动收起，支持展开。
  - 业绩为空时，展示"暂无业绩"提示。

## 4. 关键交互流程

- 登录后进入任务类型选择页，客户经理选择商户类型：
  - 若选择"存量商户"，则进入任务列表页（商户）。
  - 若选择"目标商户"，则进入任务列表页（目标商户）。
- 商户领取：客户经理在商户列表页选择商户，弹窗确认后领取，该商户下所有任务都将由该客户经理负责。
  - 若领取失败，弹窗提示并刷新。
- 任务处理：在商户详情页按状态分组，支持去处理、重新提交、查看详情等。
  - 处理过程中如遇网络异常，支持重试或保存草稿。
- 新增商户：点击新增目标商户，填写表单并上传照片，提交后回到列表。
  - 未填写完整时禁止提交。
- 地图模式：点击地图标记或底部列表项，联动高亮并展示商户卡片。
  - 地图加载失败时允许重试。
- 商户转化：在目标商户详情页支持意向转化，流程可配置。
  - 转化失败时提示原因。
- **通知提醒交互流程**：
  - 客户经理领取商户后，系统记录领取时间。
  - 商户领取后有3天有效期，系统会在到期前1天自动推送提醒通知。
  - 用户点击"去处理"可直接跳转到商户任务处理界面，处理后提醒自动消失。
  - 若任务被驳回，系统在状态变更时推送驳回提醒，用户点击"重新提交"可跳转到编辑界面。
  - 所有通知均支持手动关闭。

## 5. 主要界面说明

- 顶部导航栏：统一风格，支持返回、通知、更多操作。
- 搜索/筛选/排序：支持多条件组合，提升查找效率。
- 商户卡片：信息分组清晰，标签/状态/任务数一目了然。
  - 超时、被驳回等状态有明显高亮。
- 地图模式：支持聚合、联动卡片。
- 表单/弹窗：交互友好，必填项校验、操作确认。
- **通知卡片**：
  - 位置：商户任务详情页顶部，悬浮或嵌入式展示。
  - 样式：高亮色块、图标、简明文字，支持动画。
  - 类型：到期提醒、驳回提醒。
  - 操作：支持"去处理""重新提交"按钮，或关闭按钮。
- **异常与边界场景**：
  - 所有页面均需考虑网络异常、无数据、权限不足、操作失败等情况，提供友好提示与重试入口。
  - 表单页面需防止重复提交。
  - 图片、地图等外部资源加载失败时，展示占位图和重试。

## 6. 业务规则

- 商户领取后有3天处理时限，到期前1天提醒，过期需重新领取。
- 客户经理领取商户后，该商户下的所有任务都由该客户经理负责处理。
- 新增商户需填写必填项并上传照片。
- 任务状态流转：待处理→审核→已完成（或驳回→重新提交→审核）。
- 商户可转化为正式商户，转化后信息同步。
- 业绩录入需与商户、任务关联。
- **通知提醒规则**：
  - 商户领取后到期前1天，自动触发到期提醒。
  - 任务被驳回时，立即推送驳回提醒。
  - 通知内容需包含商户名称、状态、操作建议。
  - 通知可在处理后自动消失或手动关闭。
- **异常与边界规则**：
  - 所有操作需校验权限，权限不足时提示。
  - 重要操作需二次确认。
  - 关键数据变更需有日志记录。

## 7. 非功能需求

- 响应式设计，适配主流手机屏幕。
- 操作流畅，交互动画自然。
- 数据安全，表单校验、异常处理。
- 支持后端接口对接，数据实时同步。
- 兼容主流浏览器与WebView。
- 重要操作有埋点与日志，便于追溯。

- 交互细节参考原型与页面代码，支持后续灵活扩展。
- 详细字段、接口、流程可根据实际业务补充完善。
- 建议定期回顾与优化用户体验。
